# Home Depot Mexico stores to query.
#
# Format: sales_channel,store_label,city
#   - sales_channel: the VTEX `sc` id used by homedepot.com.mx when that
#     specific store is selected on the site. This is what delivers per-store
#     pricing through the catalog API.
#   - store_label:   the store name as shown on the site (e.g. "Monterrey Valle").
#   - city:          the city the store is located in (for the Excel output).
#
# --------------------------------------------------------------------------
# HOW TO FILL IN THE `sc` ID FOR EACH STORE (one-time setup)
# --------------------------------------------------------------------------
# 1. Open https://www.homedepot.com.mx/ in Chrome or Firefox.
# 2. Open DevTools (F12) -> Network tab. Filter by `sc=`.
# 3. On the site, click the store selector and pick the store you want.
# 4. Watch the requests: the calls to /api/catalog_system/... will include a
#    `?sc=<NUMBER>` query parameter. That <NUMBER> is the sales-channel id
#    for the store you just selected.
# 5. Replace the `<SC>` placeholder on the matching line below with that id.
# 6. Repeat for each store.
#
# For cities with more than one physical Home Depot, duplicate the city line
# (one row per store) and fill in each store's own sales-channel id and name.
# --------------------------------------------------------------------------
